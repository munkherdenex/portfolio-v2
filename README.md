# 🚀 Munkh-Erdene's Portfolio

A modern, responsive portfolio website showcasing my projects, skills, and experience as a Software Developer.

**Live Demo:** [https://munkhuu.vercel.app](https://munkhuu.vercel.app)

## ✨ Features

- **Modern Design** - Built with Next.js 16 and Tailwind CSS for a sleek, contemporary look
- **Smooth Scrolling** - Seamless navigation between sections with smooth scroll behavior
- **Responsive Layout** - Fully responsive design that works beautifully on all devices
- **Interactive Gallery** - Lightbox gallery with keyboard navigation and smooth transitions
- **Contact Form** - Functional contact form with real-time validation and feedback
- **Resume Section** - Dedicated resume section with experience, education, and skills
- **Project Showcase** - Interactive project cards with detailed descriptions and live links
- **Dark Theme** - Eye-friendly dark theme with gradient accents

## 📁 Project Structure

```
src/
├── app/
│   ├── layout.tsx          # Root layout with header and footer
│   ├── page.tsx            # Home page with hero section
│   └── globals.css         # Global styles and theme
├── components/
│   ├── sections/           # Page sections
│   │   ├── about.tsx       # About section
│   │   ├── projects.tsx    # Projects showcase
│   │   ├── resume.tsx      # Resume/CV section
│   │   ├── gallery.tsx     # Photo gallery
│   │   ├── contact.tsx     # Contact form
│   │   ├── header.tsx      # Navigation header
│   │   └── footer.tsx      # Footer
│   └── ui/                 # Reusable UI components
public/
└── img/                    # Gallery images
```
